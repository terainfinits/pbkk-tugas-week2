Cara menjalankan di lokal, command berikut di PowerShell folder project:
1. composer install
2. Copy-Item .env.example .env
3. php artisan key:generate
4. php artisan view:clear
5. New-Item database\database.sqlite -ItemType File
6. php artisan migrate
7. npm install
8. npm run build
9. php artisan serve
